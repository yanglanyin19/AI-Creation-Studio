# 技术选型评估矩阵：个人 AI 创作 WebUI

- 调研日期：2026-11-20
- 调研方式：GitHub API 核实仓库元数据 + 读取 README / LICENSE / 关键源码目录；basketikun/infinite-canvas 已本地跑通，Agent Graph 服务已用 mock OpenAI 接口验证
- Star 数、最近提交均为 2026-11-20 通过 GitHub API 获取
- 本文记录选型结论与实施边界；业务代码在 `app/`

## 1. 结论摘要（最终选型）

**最终 base：`basketikun/infinite-canvas`（10,519★，MIT，React + Vite）**

理由：

- **许可证安全**：MIT，后续商用/分发没有阻塞；huobao-canvas 的 CC BY-NC-SA 4.0 已排除。
- **最贴近截图**：现有首页、图片工作台、视频页、画布、资产、提示词、配置页齐全；深色 + 点阵背景已具备，改造量最小。
- **轻量**：507 个文件（对照 Toonflow 2,717 个），React 技术栈，浏览器直连 OpenAI 兼容接口，不需要本地 GPU。
- **已有能力**：无限画布（拖拽/缩放/连线/小地图/撤销重做/分组）、文生图/图生图/参考图编辑、视频生成与轮询、BYOK、素材库、提示词库、MCP Canvas Agent 骨架。

**范围收敛（已确认）：**

- 暂不做数字人；不引入 ComfyUI 式复杂节点图。
- 仅接云端 API，不做本地推理。
- 画布保持「少量节点 + 预设模板」的简单形态，配套好节点内容。
- 必须支持 Agent 通过 JSON Graph 操作画布；新增一个轻量 Node 服务补齐服务端 Graph 存储与 MCP/REST 工具。

**主要缺口：** 当前画布数据存在浏览器 localforage，Agent 写入依赖打开的浏览器页面。需要补一个可选的服务端 Graph 服务，并让前端与其同步；这是接下来最重要的工作。

**已排除的 base：**

| 项目 | 原因 |
|---|---|
| `chatfire-AI/huobao-canvas` | 功能最全（服务端队列 + 11 家 provider），但 CC BY-NC-SA 4.0 禁止商用；不满足「未来可能商用」 |
| `HBAI-Ltd/Toonflow-app` | 22.3k★ / MIT，能力很强，但产品是「短剧工厂」，2,717 个文件，域耦合重；与「足够轻量 + 截图 UI」冲突 |
| `tong-io/tongflow` | AGPL-3.0，网络使用即触发源码披露；无数字人；产品形态是通用工作流平台 |
| `zhengxinlan1995-code/Tapnow-Studio--` | GPL-3.0，HTML 单页，最近提交 2026-01，已停滞 |
| `crisng95/flowboard` | 无 LICENSE，依赖 Google Flow + Claude CLI，不是自托管 BYOK |
| `ZeroLu/open-canvas` | MIT 但 alpha，默认 provider 绑定 Cyberbara，无服务端队列/Agent |

## 2. 前提核查（先纠正任务描述里的偏差）

| 任务中的说法 | 核实结果 | 影响 |
|---|---|---|
| huobao-canvas 支持 11 家厂商、Docker 单镜像、BYOK | **属实**。`apps/web/src/config/providers/` 下确有 11 个 provider 文件；`apps/server` 是零 npm 依赖 Node + `node:sqlite`，含 `runs` 队列；Dockerfile 单镜像 | 可直接作为 base |
| huobao-canvas 可安全商用 | **不成立**。LICENSE 正文为 `Attribution-NonCommercial-ShareAlike 4.0 International` | 个人自用可以；商用/闭源分发不行 |

| HuFakai main 已移除视频/音频，需切 `codex/video-audio-upstream-v0.3.3` | **属实**，README 明确说明 | 该分支维护状态弱于上游 |
| basketikun 的画布/视频能力 | **属实但定位有摇摆**。README 首段写「面向图片创作」，功能列表和代码里仍有视频页、视频节点、`asyncVideo` 相关逻辑 | 选它需要实际跑一遍验证视频节点完整度 |
| `tongflow` 提供 `applyGraphPatch` / `readCanvas` 等 agent graph tools | **基本属实**。`packages/tongflow/src/core/agent/tool-defs.ts` 中确有 `apply_graph_patch`、`read_canvas`、`validate_workflow`、`describe_node_type`；未找到名为 `TONGFLOW_TOOL_DEFS` 的导出，任务里的常量名不准确 | 可借鉴 ABI 设计；**AGPL 代码不可复制进非 AGPL 项目** |
| `agent-flow-canvas` | **该名称的仓库不存在** | 不能作为依赖；相关能力看 Toonflow / tongflow |
| InfiniteTalk 提供 ComfyUI 和 WebUI 两种运行版本 | 仓库真实存在（8,442★ / Apache-2.0），README 宣称支持 ComfyUI；最近提交 2026-05-22 | 需在目标 GPU 环境实测 ComfyUI 工作流 |
| EchoMimicV2 适合半身数字人 | **属实**（4,677★ / Apache-2.0 / CVPR 2025，最近提交 2026-11-17） | 与 InfiniteTalk 二选一，实测口型和速度 |
| OpenTalking 提供 WebUI 和实时对话编排 | **属实**（3,400★ / Apache-2.0，最近提交 2026-09-04） | 只有「实时对话」场景才需要 |
| SadTalker 仍可作为主力 | **不建议**。14,212★ 但最近提交 2024-06-26，且 LICENSE 为 NOASSERTION | 仅作备选，先核对许可 |
| crisng95/flowboard 可作为无限画布参考 | 仓库存在（505★），但无 LICENSE，且核心依赖 Google Flow + Claude CLI | 不可复用代码，也不满足自托管 BYOK |

**结论：任务的技术方向成立，但 base 选择不能只看功能列表，必须把「许可证 + Agent 是否依赖浏览器 + 服务端队列」一起看。**

## 4. 最终方案：base + 自研缺口

### 4.1 以 `basketikun/infinite-canvas` 为 base

直接复用（不重写）：

- React 自研无限画布：拖拽、缩放、连线、框选、小地图、撤销重做、分组、导入导出
- 文本 / 图像 / 视频 / 音频 / 配置 / 分组六类节点
- 文生图、图生图、参考图编辑、视频生成 + 异步轮询
- OpenAI 兼容 / Gemini / 自定义脚本三种调用格式，BYOK
- 首页、图片工作台、视频工作台、资产、提示词、配置页
- Canvas Agent MCP 骨架（本地 canvas-agent）

自研 / 改造（已开始）：

1. 左侧图标导航 + 首页创作输入区 + 工具卡片（对齐截图 1）
2. 图片/视频工作台双栏化：左配置、右结果，历史记录改为抽屉（对齐截图 2）
3. 画布空状态 + 4 个预设模板：文生图、图片编辑、全民嗨跳、多图生视频（对齐截图 3）
4. 轻量 Node 服务：服务端 JSON Graph 存储 + `read_canvas` / `apply_patch` / `run_node` / `run_graph` / `get_task_status` / `describe_node_types` + MCP 入口
5. 画布内任务状态、失败重试、素材入库的增量补齐

### 4.2 万相 3.0 视频自定义协议（已实现）

按千问 AI 平台文档接入 `wan3.0-video` / `wan3.0-video-prime`：

- 创建任务：`POST {baseUrl}/services/aigc/video-generation/video-synthesis`
- 查询任务：`GET {baseUrl}/tasks/{task_id}`
- 认证：`Authorization: Bearer {apiKey}`，并必须带 `X-DashScope-Async: enable`
- 输入：`input.prompt`；图/视频/音频用 `input.media[{ type, url }]`，类型为 `first_frame` / `last_frame` / `reference_image` / `reference_video` / `reference_audio`
- 参数：`resolution`（480P/720P/1080P）、`ratio`、`duration`（2–30 或 -1）、`audio`、`prompt_extend`、`watermark`
- 结果：轮询到 `output.task_status=SUCCEEDED` 后取 `output.video_url`

实现位置：视频调用脚本模板「万相 3.0 视频」（`web/src/services/api/model-plugin.ts`）。支持首帧/首尾帧与全能参考模式，参考视频/音频自动转 Data URL，单次轮询超时 10 分钟。配置页另提供「添加万相 3.0 渠道」一键预设，同时加入 `wan3.0-video` 与 `wan3.0-video-prime`，默认选中 prime；详细步骤见 README「接入千问万相 3.0 视频」。

实测结果（2026-11-20，2 秒/480P）：

- `wan3.0-video` 返回 `403 Free quota exhausted`，`wan3.0-video-prime` 可用。
- prime 的文生视频、首帧、首尾帧、参考图、参考音频、参考视频、视频编辑、视频延长均成功。
- `duration=1` 不被支持，最低 2 秒。
- 参考视频公网 URL 可能被平台拒绝下载；使用 Base64 data URL 可成功。
- 生成结果已保存到 `test-output/wan30/`（本地 MP4，平台 URL 24 小时过期）。

## 6. 风险提示

1. **许可证**
   - 最终 base `basketikun/infinite-canvas` 为 MIT，可商用；第三方模型、素材、字体仍各有许可。
   - 已排除 huobao（CC BY-NC-SA 4.0，禁止商用）与 tongflow（AGPL-3.0，网络使用触发源码披露）。

2. **Agent 并发一致性**
   - 当前画布是「浏览器 localforage 权威」。新增服务端 Graph 后必须加 `revision` 字段和乐观锁；patch 冲突返回 409，避免 Agent 与人工编辑互相覆盖。
   - 前端与服务端同步时只传节点/连线/参数，不传图片二进制；图片继续走现有素材存储。

3. **API Key 隐私**
   - 当前 Key 存在浏览器本地，由前端直连 API，隐私最好。
   - 若 Agent 服务端执行 `run_node`，Key 必须由调用方按请求传入或存本地服务端加密存储；不得写日志、不得写入任务记录、不得发往第三方。
   - 服务端只监听 `127.0.0.1`，默认不暴露公网。

4. **数字人（暂缓）**
   - 已确认暂不做数字人；后续若恢复，需要 GPU 和 ComfyUI/InfiniteTalk，另立里程碑。

5. **上游稳定性**
   - basketikun README 明确「开发阶段，不保证历史数据兼容」。已 fork 到本地 `app/`，后续锁定提交，不直接跟 main。
   - 视频节点完整度需要在真实 API 环境下再验证。

6. **UI 版权**
   - 你发的截图是第三方产品界面。只实现布局、交互和视觉风格，不复刻其 Logo、插画、图标等受版权保护的素材。

7. **任务描述中的不准确处**
   - `agent-flow-canvas` 不存在；`tongflow` 的常量名不准确；`flowboard` 无许可证。这些不能作为硬依赖。

## 7. 已确认的决策

| 决策 | 结论 |
|---|---|
| Base | `basketikun/infinite-canvas`（MIT） |
| 数字人 | 暂不做 |

| 产品形态 | 轻量、少节点、预设模板、UI 对齐三张截图 |
